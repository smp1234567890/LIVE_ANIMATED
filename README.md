# AURA — Hypnotic & Elegant Animated Website

An ultra-refined, aesthetic, and engaging digital experience built with modern motion design and procedural canvas technology.

## ✨ Key Features
- **Cinematic Dark Luxury Aesthetic**: Champagne gold & deep violet luminescence with high-contrast typography (Syne & Cinzel).
- **Inertia Smooth Scrolling**: Butter-smooth 60+ FPS motion powered by Lenis + GSAP ScrollTrigger.
- **Magnetic Custom Cursor**: Lerp physics, magnetic attraction to buttons, and contextual badges on card hover.
- **Procedural Particle Nebula**: Dynamic WebGL/Canvas ambient constellation reacting to mouse movements.
- **Sensory Harmonic Lab**: Interactive real-time wave distortion shader with mouse proximity dynamics.
- **Spatial Audio Atmosphere**: Native Web Audio API ambient drone and harmonic tone synthesizer (no heavy audio files required).
- **Interactive Bento & Spotlight Cards**: Light borders that follow the user's cursor.
- **Responsive Architecture**: Fully mobile and desktop responsive using Tailwind CSS.

## 🚀 Live Preview
Open `index.html` directly in your browser or run:
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).
